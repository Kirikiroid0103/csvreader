# Тестовые датасеты

| Файл | Описание | Ожидаемое поведение |
|------|----------|---------------------|
| `sales_10000.csv` | Нормальный датасет: 10 000 строк, 8 столбцов (числовые, категориальные, даты) | Полная загрузка, аналитика, графики, фильтры |
| `broken_csv.csv` | Битый CSV: незакрытые кавычки, несовпадение числа полей, пустые строки | Частичная загрузка без краха, статус с числом строк |
| `text_in_numeric.csv` | Текст в числовых полях: `N/A`, `ошибка`, пустые значения | Тип определяется как numeric/mixed, аналитика считает только валидные числа |
| `missing_values.csv` | 50 строк с пропусками (10–20% в каждом столбце) | Пропуски подсчитаны в сводке, аналитика работает |
| `no_numeric.csv` | 30 строк, только текстовые столбцы | Гистограмма и scatter недоступны, круговая работает |
| `empty_file.csv` | Пустой файл (0 байт) | Сообщение «Файл пуст или не содержит заголовков» |
| `headers_only.csv` | Только строка заголовков, без данных | Заголовки распознаны, строк = 0 |
