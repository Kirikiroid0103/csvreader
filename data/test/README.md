# Тестовые датасеты

| Файл | Описание | Ожидаемое поведение |
|------|----------|---------------------|
| `sales_10000.csv` | Нормальный датасет: 10 000 строк, 8 столбцов (числовые, категориальные, даты) | Полная загрузка, аналитика, графики, фильтры |
| `broken_csv.csv` | Битый CSV: незакрытые кавычки, несовпадение числа полей, пустые строки | Ошибка: «Битый CSV: обнаружены незакрытые кавычки» |
| `text_in_numeric.csv` | Текст в числовых полях: `N/A`, `ошибка`, пустые значения | Ошибка: «В числовых столбцах обнаружен текст вместо чисел» |
| `missing_values.csv` | 50 строк с пропусками (10–20% в каждом столбце) | Загрузка с предупреждением о строках с пропущенными значениями |
| `no_numeric.csv` | 30 строк, только текстовые столбцы | Ошибка: «В файле нет числовых столбцов» |
| `empty_file.csv` | Пустой файл (0 байт) | Ошибка: «Файл пуст. Загрузите CSV с данными.» |
| `headers_only.csv` | Только строка заголовков, без данных | Ошибка: «Файл не содержит строк данных — только заголовки.» |
