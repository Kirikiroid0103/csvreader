# CSV Viewer

Клиентское веб-приложение для загрузки и анализа CSV-файлов.

## Возможности
- загрузка CSV через кнопку выбора файла и drag'n'drop;
- автоматическое определение разделителя: `,`, `;`, `\t`, `|`;
- определение типов столбцов: числовой, категориальный, дата, смешанный;
- сводка: строки, столбцы, пропуски, файл;
- аналитика:
  - числовые: среднее, медиана, минимум, максимум, стандартное отклонение, пропуски;
  - категориальные: уникальные значения, пропуски, топ-5 по частоте;
- визуализация:
  - числовые: столбчатая диаграмма метрик;
  - категориальные: топ-5 значений с барами;
- фильтры:
  - по категориальному столбцу и значению;
  - по числовому столбцу и диапазону;
- таблица первых 20 строк с горизонтальной прокруткой;
- адаптивная вёрстка до 360 px;
- понятные сообщения об ошибках.

## Запуск
Проект полностью клиентский. Можно открыть `index.html` в браузере.

Для кнопки «Загрузить пример» рекомендуется запустить локальный сервер, потому что `fetch` локальных файлов может быть ограничен при открытии через `file://`.

Пример:
```bash
python -m http.server 8000
```
Затем открыть:
```
http://localhost:8000/
```

## Код
- `js/data.js` — парсинг CSV, типы, утилиты;
- `js/analytics.js` — расчёт метрик;
- `js/charts.js` — отрисовка визуализаций;
- `js/app.js` — состояние, события, сборка интерфейса.
