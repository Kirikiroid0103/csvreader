Вот пошаговая инструкция для публикации проекта csv_viewer_project на GitHub и локального развёртывания.
1. Подготовка проекта
Убедитесь, что в корне проекта есть файл .gitignore, чтобы не коммитить лишнее:
gitignore
# Игнорируем кэш и системные файлы
.DS_Store

2. Инициализация Git-репозитория
Откройте терминал в папке проекта (csv_viewer_project) и выполните:
bash
git init
git add .
git commit -m "Initial commit: CSV Viewer with analytics and visualization"
3. Создание репозитория на GitHub
Зайдите на GitHub и нажмите New repository (или + → New repository).
Задайте имя (например, csv-viewer).
Выберите видимость: Public или Private.
Не ставьте галочки на добавление README, .gitignore или license (мы уже всё подготовили локально).
Нажмите Create repository.
4. Публикация на GitHub
Свяжите локальный репозиторий с удалённым и отправьте код:
bash
git remote add origin https://github.com/<ВАШ_ПОЛЬЗОВАТЕЛЬ>/csv-viewer.git
git branch -M main
git push -u origin main
Замените <ВАШ_ПОЛЬЗОВАТЕЛЬ> на ваш логин GitHub.

5. Локальное развёртывание
Так как проект — это чистый фронтенд (HTML/CSS/JS), для локального запуска нужен любой статический веб-сервер.
Вариант А: Python (самый простой)
Если у вас установлен Python 3:
bash
cd csv_viewer_project
python3 -m http.server 8000
Откройте в браузере: http://localhost:8000
Вариант Б: Node.js (Live Server)
Если у вас установлен Node.js:
bash
# Установите live-server глобально (один раз)
npm install -g live-server

# Запустите
cd csv_viewer_project
live-server
Откройте в браузере: http://127.0.0.1:8080
Вариант В: VS Code
Установите расширение Live Server.
Откройте папку csv_viewer_project в VS Code.
Кликните правой кнопкой мыши по index.html → Open with Live Server.

После запуска сервера откройте страницу в браузере.
